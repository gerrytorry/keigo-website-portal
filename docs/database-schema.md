# Skema relasional
User Django → StudentProfile one-to-one (kolom scalar CV, status/revision). Education, WorkExperience, FamilyMember, Certificate, JapanHistory many-to-one ke siswa. Document menyimpan revisi private dan status. CVVersion menyimpan snapshot immutable dan nomor versi unik per siswa. Job berisi lowongan dan persyaratan terstruktur. Application unik (siswa, job), FK PROTECT ke CVVersion. ApplicationHistory append-only. Interview terkait application. Notification milik recipient dan read_at. AdminNote punya visibility eksplisit. AuditEvent append-only. LoginAttempt untuk throttling persisten.
Transaksi dan compare-and-swap revision mencegah autosave/aksi admin menimpa perubahan orang lain. FK dan unique constraints dijalankan database. Tidak cascade-delete riwayat kandidat melalui UI.
